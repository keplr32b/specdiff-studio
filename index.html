What it does

How to run (Studio)

  1. allow_host — pass hostname only, e.g. docs.genlayer.com
  2. create_check — check_id, spec_url, impl_url, title
  3. run_check / recheck — wait for consensus; read returned label
  4. get_last / get_history — report JSON on-chain
